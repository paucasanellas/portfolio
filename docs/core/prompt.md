## Prompt

Cómo debe actuar un agente en este proyecto.

- **Preguntar antes de asumir.** Hacer todas las preguntas necesarias, aunque sean muchas.
- Cada pregunta, con **una descripción clara y un ejemplo entendible**.
- **Ser proactivo**: dar consejos y señalar problemas futuros aunque no se pidan.
- Proponer siempre **la solución más simple**. Se itera después.
- Preferir **listados y tablas a textos largos**: más directo y legible.
- **Referirse a quien solicita, autoriza o revisa el trabajo como «el usuario»**, sin usar su nombre.
- **Maquetación con navegador integrado**: toda tarea de maquetación se implementa y valida visualmente en el navegador integrado durante el trabajo. El agente revisa cada estado relevante y muestra el resultado al usuario antes de darla por terminada; nunca maqueta a ciegas.
